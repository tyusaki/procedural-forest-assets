# Credits and provenance

- **Project practice — 张逸伦 / tyusaki**: tree parameter studies, UE material and wind exercises, asset inspection/export usage, and result review.
- **Tree source**: the editable publication copy comes from the current Forest Shader Lab practice scene. It uses project trunk, branch and foliage masters. Some reference node structures and artistic layouts were prepared with AI assistance; the supplied crown-layout template is a reference asset, not a claim of a fully automatic layout algorithm authored from scratch.
- **Python tools**: the inspection script, early single-mesh exporter and FSL Batch Exporter were written and refined with AI assistance. The batch exporter calls Blender's built-in FBX exporter.
- **Publication preparation**: an isolated copy of the current scene was cleaned and rendered for this repository. Duplicate display objects were removed, tree placement/camera/lighting were arranged, and geometry equality was checked. The working scene was not overwritten.
- **Reports**: sample outputs were generated from the published source. Machine-specific paths in the public JSON copies were converted to repository-relative paths; geometry and check results were retained.

This package contains the project's Blender assets and tools. It does not bundle the Unreal Engine software, third-party asset packs, or game reference screenshots. Blender and Unreal Engine remain products of their respective owners.
